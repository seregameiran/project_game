## 📖 О проекте

**Billy's Adventure** - это образовательная RPG с видом сверху, разработанная в рамках учебной практики в ДВФУ. Игрок управляет персонажем по имени Билли, которому предстоит доказать трём преподавателям математики, что он разбирается в предмете лучше них.

В пошаговых боях арифметические операции превращаются в атаки, влияющие на параметры **X** (урон игрока) и **Y** (урон босса). Чтобы победить, нужно не только правильно выбирать атаки, но и решать математические примеры, которые задают боссы.

Проект полностью рабочий, собран в **EXE - файл** и готов к запуску на Windows.

## 🕹️ Управление

| Действие | Клавиши |
|----------|---------|
| Движение | `W/A/S/D` или `↑/↓/←/→` |
| Взаимодействие с NPC / боссом / дверью | `E` |
| Открыть меню паузы | `ESC` |
| Выбрать атаку в бою | `1` (сложение), `2` (вычитание), `3` (умножение), `4` (деление) |
| Ввод ответа на пример | Цифры `0-9` |
| Подтвердить ответ | `ENTER` |
| Навигация в меню | `W/S/↑/↓` или `A/D/←/→` |

## 🧠 Боевая система

### Параметры
- **X** - урон игрока (растёт от атаки «Сложение»)
- **Y** - урон босса (растёт от атаки босса «Сложение»)

### Атаки игрока

| Клавиша | Атака | Эффект |
|---------|-------|--------|
| `1` | Сложение | X = X + 1, урон по боссу = X |
| `2` | Вычитание | Y = Y - 2, урон по боссу = 2 |
| `3` | Умножение | Следующая атака (Сложение или Вычитание) срабатывает с **удвоенным эффектом** |
| `4` | Деление | Следующий удар босса наносит **в 2 раза меньше урона** |

> ⚠️ Атаки открываются постепенно после правильного решения обучающих примеров.

### Атаки босса

| Атака | Частота | Правильный ответ | Ошибка |
|-------|---------|------------------|--------|
| Базовая | Обычные ходы | - | HP игрока - Y |
| Сложение | Раз в 2 хода | Y = Y + N | Y = Y + N × 2 |
| Вычитание | Раз в 3–4 хода | X = X - 1 | X = X - 2 |
| Умножение | Раз в 4–5 ходов | Следующий удар ×2 | X = X / 1.5, Y = Y × 2 |
| Деление | Раз в 4–5 ходов | X = X / 2 | X = X / 2, Y = Y × 1.5 |

> **N** - случайное число, зависящее от босса:
> - 1-й босс: N от 1 до 2
> - 2-й босс: N от 1 до 3
> - 3-й босс: N от 1 до 4

## 🗺️ Локации и боссы

| Локация | Название | Босс | Описание |
|---------|----------|------|----------|
| 1 | Дорога | - | Дорога с деревьями, морем и остановками. Можно поговорить с NPC |
| 2 | Вход в школу | - | У школы можно встретить второго NPC |
| 3 | Класс | **Внучка** | Первый босс. Открывает атаки «Сложение» и «Вычитание» |
| 4 | Класс | **Отец** | Второй босс. Открывает атаку «Умножение» |
| 5 | Класс | **Бабушка** | Третий босс. Открывает атаку «Деление» |

> Переход на локации 3–5 открывается только после победы над предыдущим боссом.

## 🚀 Установка и запуск

### Способ 1: Из исходников (Python)

```bash
# Клонируем репозиторий
git clone https://github.com/seregameiran/BillysAdventure.git
cd BillysAdventure

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем игру
python src/main.py
```

### Способ 2: Готовый EXE (Windows)

1. Скачайте файл `BillysAdventure_Setup.exe` из раздела **Releases**
2. Запустите установку
3. Играйте!
